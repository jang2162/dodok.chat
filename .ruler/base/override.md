# base 바꿈 — 이 프로젝트에서 더하는 브리프 규칙

## 브리프의 건드릴 파일은 호출자와 시험 파일 이름까지 적는다
바꾸는 절: `base/09-worker-brief.md`

브리프의 「건드릴 파일」 목록을 쓸 때, 고칠 길이 바꾸는 함수의 호출자와 「무엇을 어떻게」에 적은 시험 파일을 이름 그대로 함께 싣는다.

- **Why:** 워커는 목록을 경계로 읽는다. 이월 배치(2026-10-31)에서 둘 다 겪었다 — 함수에 인자를 더해야 했는데 유일한 호출자가 목록에 없어 워커가 묻고 답을 받는 데 10분 넘게 막혔고, 시험 파일을 글롭(`runners.*.test.ts`)으로만 적은 줄은 워커가 목록을 좁게 읽어 자연스러운 자리 대신 새 시험 파일을 만들었다.
- **How to apply:**
  - 줄의 고칠 길이 함수의 인자·반환을 바꾸면 그 함수의 호출자(codegraph)도 건드릴 파일에 함께 적는다 — 빠지면 워커가 목록 밖 파일로 멈추고 묻는다.
  - 「무엇을 어떻게」에 적은 시험 파일은 글롭이 아니라 같은 이름으로 목록에 싣는다 — 글롭으로만 적으면 워커가 목록을 좁게 읽어 새 파일을 만든다.
