# Phase 2 ④ PWA·푸시 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> 이 저장소에서는 Orca 워커가 태스크를 맡는다(`CLAUDE.md` 「작업 방식」). 태스크 하나 = 워크트리 하나 = 브리프 하나.

**Goal:** dodok 을 설치형 PWA 로 만들고, 오프라인에서 최근 채널을 읽게 하고, 탭이 닫혀 있어도 멘션·승인 요청·릴레이 한도를 웹 푸시로 알린다.

**Architecture:** 웹은 `vite-plugin-pwa`(`injectManifest`)로 서비스 워커 하나(`src/sw.ts`)를 만든다 — 앱 껍데기 미리 저장, 푸시 → 알림, 알림 누르기 → 그 채널. 오프라인 사본은 TanStack Query 를 골라 IndexedDB 에 저장한다. 서버는 새 `push` 모듈이 버스 이벤트를 받아 받을 사람·알림 내용을 정하고, wire 로 받은 「보고 있는 채널」이면 거르고, `web-push`(VAPID)로 보낸다.

**Tech Stack:** Vite 8.3(rolldown) · `vite-plugin-pwa` 1.3.0 · `workbox-precaching`·`workbox-routing` 7.4.1 · `@tanstack/query-persist-client-core`·`@tanstack/query-async-storage-persister` 5.103.x · `idb-keyval` 6.3.0 · 서버 `web-push` 3.6.7(+`@types/web-push` 3.6.4) · Fastify 5 · Socket.IO 4.8 · zod 4

**Spec:** `docs/superpowers/specs/2026-09-23-pwa-push-design.md` — 결정 0장, 서비스 워커 3장, 오프라인 4장, 푸시 5장, 설정 6장, 검증 8장. **태스크를 시작하기 전에 스펙의 해당 장을 읽는다.**

## Global Constraints

- **의존성은 정확 버전으로 핀**(`pnpm add -E`): 웹 `vite-plugin-pwa@1.3.0`·`workbox-precaching@7.4.1`·`workbox-routing@7.4.1`·`workbox-window@7.4.1`·`idb-keyval@6.3.0`·`@tanstack/query-persist-client-core`·`@tanstack/query-async-storage-persister`(기존 `@tanstack/react-query` 5.103.1 과 같은 5.103.x — 맞는 버전을 고른다), 서버 `web-push@3.6.7`·`@types/web-push@3.6.4`(dev). 그 밖의 추가는 없다. 아이콘 생성은 `pnpm dlx @vite-pwa/assets-generator`(영구 의존성 아님).
- **알림에는 누가·어디·무엇만** 싣는다(스펙 결정 1). 메시지 본문·툴 인자·승인 제목/설명은 페이로드에 **넣지 않는다**. 문구: 「@<핸들>이/가 #<채널>에서 불렀습니다」 · 「#<채널>에 승인 요청이 있습니다」 · 「#<채널>의 에이전트 대화가 한도에 닿았습니다」 · 제목은 늘 `dodok` · 파싱 실패 「dodok — 새 알림」.
- **보고 있으면 안 보낸다**(결정 2) — 받는 사람의 소켓 중 `visible && channelId === 이벤트 채널` 이 하나라도 있으면 그 사람은 건너뛴다.
- 알림 URL 은 **같은 출처 상대 경로** `/c/<uuid>` · `/c/<uuid>/activity` 만. 그 밖은 `/`.
- 오프라인 사본: 채널 목록·`me`·에이전트 + **최근 본 채널 5개**의 멤버·타임라인(**최근 메시지 50개**, `pending` 제외), 최대 나이 **7일**, 앱 빌드가 바뀌면 버림, **로그아웃·401 이면 지움**.
- 서비스 워커는 `/api/`·`/socket.io/` 와 첨부를 **저장하지 않는다**.
- 새 버전은 **자동 갱신하지 않는다** — 토스트 「새 버전이 있습니다」 + 「새로고침」.
- 이 기기에 푸시가 켜져 있으면 **탭 안 승인 알림은 쉰다**(결정 8).
- VAPID: 환경변수 `VAPID_PUBLIC_KEY`·`VAPID_PRIVATE_KEY`(둘 다 있어야) 아니면 `<DATA_DIR>/vapid.json`(0600, 없으면 만듦). `VAPID_SUBJECT` 기본 `mailto:dodok@localhost`(개발용) — **주체의 호스트가 `localhost`·`127.0.0.1`·`*.local` 이면 서버 시작 때 warn 한 줄**(Apple Push 는 이런 주체를 `403 BadJwtToken` 으로 거부한다, web-push#947·#988). 실기기·Safari 로 보내는 배포는 실제 연락처로 설정한다. **비밀 키는 로그에 싣지 않는다**(로거 가림 목록에 `VAPID_PRIVATE_KEY`·`privateKey`). 구독 `keys` 도 로그에 싣지 않는다.
- **알려진 경고(결함 아님, 고치지 않는다)**: 웹 빌드의 `inlineDynamicImports option is deprecated`(vite-plugin-pwa#912)·`[baseline-browser-mapping] … over two months old`(#928), 서버의 `url.parse()` 폐기 경고 DEP0169(web-push 3.6.7 내부, #978).
- REST 경로는 `/api/v1/...`. 접근 규칙은 세션 사용자(`requireSession`).
- 5173 은 이 머신의 **다른 프로젝트**다 — 브라우저 확인은 5180(`APP_ORIGIN`·`DODOK_API_ORIGIN`·`--port` 를 맞춘다).
- 커밋: `git add -A`·`git commit -a` 금지, 경로 명시. Conventional Commits + 스코프(`feat(web):`·`feat(server):`·`feat(shared):`). 워커 트레일러 `Co-Authored-By: <네 실제 모델명> <noreply@anthropic.com>`.
- 끝내기 검사: 루트 `pnpm test && pnpm typecheck && pnpm lint && pnpm fmt:check`, 각 exit code, 테스트 수는 **자기 실행 출력에서** 패키지별로.

## Review Focus

1. **같은 브라우저를 두 사람이 쓴다** — A 가 푸시를 켜고 로그아웃한 뒤 B 가 로그인하면: A 의 사본(IndexedDB)이 없고, A 의 구독이 서버에서 지워졌고, B 가 켜면 같은 endpoint 가 B 에게 묶인다(A 에게 B 의 알림이 가지 않는다). → 태스크 2(upsert 옮기기)·태스크 5(로그아웃).
2. **오프라인 동안 세션이 만료** — 사본으로 뜬 뒤 연결이 돌아와 `me` 가 401 이면 사본을 지우고 로그인으로 간다(낡은 대화를 계속 보여 주지 않는다). → 태스크 4.
3. **자기 멘션·다른 채널을 보는 중** — 내가 나를 멘션하면 푸시 없음. 에이전트가 나를 멘션했는데 나는 **다른** 채널을 보고 있으면 푸시가 온다. 보이지 않는 탭(백그라운드)은 「보고 있음」이 아니다. → 태스크 3.
4. **알림 누르기** — 앱이 다른 채널에 열려 있으면 새 창이 아니라 **그 창**이 앞으로 와서 옮겨 간다. 페이로드 url 이 `https://evil.example/…`·`//evil`·`/c/../x` 면 `/` 로. → 태스크 5.
5. **작성 중 새 버전** — 새 서비스 워커가 기다려도 새로고침되지 않고, 「새로고침」을 누를 때만 바뀐다. → 태스크 1.

- [ ] **Step 4: 서비스 워커(껍데기)**

```ts
// apps/web/src/sw.ts
/// <reference lib="webworker" />
import { cleanupOutdatedCaches, createHandlerBoundToURL, precacheAndRoute } from "workbox-precaching";
import { NavigationRoute, registerRoute } from "workbox-routing";

declare const self: ServiceWorkerGlobalScope & { __WB_MANIFEST: Array<{ url: string; revision: string | null }> };

cleanupOutdatedCaches();
precacheAndRoute(self.__WB_MANIFEST);

// SPA 탐색 폴백 — /api·/socket.io 는 네트워크만(스펙 3장). 개발 모드는 매니페스트가 비어 index.html 이 없을 수 있다
if (self.__WB_MANIFEST.some((e) => e.url === "index.html")) {
  registerRoute(
    new NavigationRoute(createHandlerBoundToURL("index.html"), { denylist: [/^\/api\//, /^\/socket\.io\//] }),
  );
}

// 새 버전은 웹이 「새로고침」을 누를 때만 넘어간다(스펙 결정 7)
self.addEventListener("message", (event) => {
  if ((event.data as { type?: unknown } | null)?.type === "SKIP_WAITING") void self.skipWaiting();
});
```

`tsconfig.sw.json`(`lib: ["ES2023", "WebWorker"]`, `include: ["src/sw.ts", "src/pwa/sw-logic.ts"]`, 루트 tsconfig 의 공통 옵션 상속)을 두고 `tsconfig.json` 에서 `src/sw.ts` 를 뺀다. `typecheck` 스크립트가 둘 다 검사한다. `vite-plugin-pwa/client` 타입은 앱 tsconfig 의 `types` 에.

```ts
// apps/web/src/pwa/register.test.ts
import { describe, expect, it, vi } from "vitest";
import { startPwa } from "./register";

describe("startPwa", () => {
  it("대기 중인 새 버전이 있어도 스스로 새로고침하지 않고 onNeedRefresh 로 넘긴다 [Review Focus 5]", async () => {
    const updateSW = vi.fn(async () => {});
    let captured: { onNeedRefresh?: () => void } = {};
    const register = vi.fn((o: { onNeedRefresh?: () => void }) => {
      captured = o;
      return updateSW;
    });
    const onNeedRefresh = vi.fn();
    startPwa({ onNeedRefresh, register: register as never });
    expect(register).toHaveBeenCalledWith(expect.objectContaining({ immediate: true }));
```

```ts
// apps/server/src/modules/push/vapid.ts
/** VAPID 키(스펙 5.1). 환경변수 둘이 다 있으면 그것, 아니면 <dataDir>/vapid.json(0600). 망가진 파일은 덮어쓰지 않고 던진다 */
import { mkdirSync, readFileSync, writeFileSync } from "node:fs";
import { join } from "node:path";
import webpush from "web-push";
import { z } from "zod";

const Keys = z.object({ publicKey: z.string().min(1), privateKey: z.string().min(1) });
export type VapidKeys = z.infer<typeof Keys>;

export function loadVapidKeys(opts: { dataDir: string; publicKey?: string; privateKey?: string }): VapidKeys {
  if (opts.publicKey && opts.privateKey) return { publicKey: opts.publicKey, privateKey: opts.privateKey };
  const path = join(opts.dataDir, "vapid.json");
  let raw: string | undefined;
  try {
    raw = readFileSync(path, "utf8");
  } catch (err) {
    if ((err as NodeJS.ErrnoException).code !== "ENOENT") throw err;
  }
  if (raw !== undefined) {
    const parsed = Keys.safeParse(safeJson(raw));
    if (!parsed.success) throw new Error(`${path}: VAPID 키 파일이 망가졌다 — 지우면 새로 만들지만 모든 푸시 구독이 무효가 된다`);
    return parsed.data;
  }
  const keys = webpush.generateVAPIDKeys();
  mkdirSync(opts.dataDir, { recursive: true });
  writeFileSync(path, JSON.stringify(keys), { mode: 0o600, flag: "wx" });
  return keys;
}

function safeJson(s: string): unknown {
  try {
    return JSON.parse(s);
  } catch {
    return undefined;
  }
}
```

```ts
import type { PresenceUpdate } from "@dodok/shared";
export type Presence = ReturnType<typeof createPresence>;
/** 소켓별 「보이는가·보는 채널」(스펙 5.3). 서버 재시작 직후 몇 초는 비어 있다(스펙 10장) */
export function createPresence() {
  const bySocket = new Map<string, { userId: string; visible: boolean; channelId?: string }>();
  return {
    set(socketId: string, userId: string, p: PresenceUpdate) {
      bySocket.set(socketId, { userId, visible: p.visible, ...(p.channelId ? { channelId: p.channelId } : {}) });
    },
    drop(socketId: string) {
      bySocket.delete(socketId);
    },
    isWatching(userId: string, channelId: string): boolean {
      for (const s of bySocket.values()) if (s.userId === userId && s.visible && s.channelId === channelId) return true;
      return false;
    },
  };
}
```

```ts
import { notificationFromPush, pickClient, safeNotificationUrl } from "./pwa/sw-logic";

self.addEventListener("push", (event) => {
  let data: unknown;
  try { data = event.data?.json(); } catch { data = undefined; }
  const { title, options } = notificationFromPush(data);
  event.waitUntil(self.registration.showNotification(title, { ...options, icon: "/pwa-192x192.png", badge: "/pwa-64x64.png" }));
});

self.addEventListener("notificationclick", (event) => {
  event.notification.close();
  const url = safeNotificationUrl((event.notification.data as { url?: unknown } | null)?.url);
  event.waitUntil((async () => {
    const all = await self.clients.matchAll({ type: "window", includeUncontrolled: true });
    const i = pickClient(all.map((c) => ({ url: c.url, visibilityState: c.visibilityState, focused: c.focused })), self.location.origin);
    if (i < 0) { await self.clients.openWindow(url); return; }
    const client = all[i] as WindowClient;
    await client.focus();
    client.postMessage({ type: "navigate", url }); // 전체 새로고침 없이 라우터가 옮긴다
  })());
});

self.addEventListener("pushsubscriptionchange", (event) => {
  event.waitUntil((async () => {
    const key = await fetch("/api/v1/push/vapid-public-key", { credentials: "same-origin" }).then((r) => (r.ok ? r.json() : null)).catch(() => null) as { publicKey?: string } | null;
    if (!key?.publicKey) return;
    const sub = await self.registration.pushManager.subscribe({ userVisibleOnly: true, applicationServerKey: urlBase64ToUint8Array(key.publicKey) });
    await fetch("/api/v1/push/subscriptions", { method: "POST", credentials: "same-origin", headers: { "content-type": "application/json" }, body: JSON.stringify(sub.toJSON()) }).catch(() => undefined);
  })());
});
```
