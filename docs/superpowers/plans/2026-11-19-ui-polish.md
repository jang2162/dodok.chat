# UI 점검 반영 — 구현계획

> **For agentic workers:** 이 저장소에서는 Orca 워커가 실행한다(`docs/guides/worktree-workflow.md`). **두 줄기는 서로 다른 워크트리에서 병렬로** 돈다 — 줄기 A(Task A1~A4)와 줄기 B(Task B1~B3). 자기 줄기의 태스크만 한다.

**Goal:** 스펙 U1~U9 — 연결 상태 단추, 12px 미만 글자 없애기, 이니셜 아바타·그룹 DM 인원수, 좁은 화면 머리의 「더 보기」, 로그인 카드와 회색 비활성 주 버튼.

**Architecture:** 이니셜 아바타는 새 부품 `ui/identity-avatar.tsx` 하나가 사람·에이전트 이니셜과 색을 내고, 흩어진 `AvatarFallback text-[10px]` 자리들이 그것을 쓴다. 좁은 화면 머리는 새 `app/layout/HeaderOverflow.tsx` 틀에 머리마다 항목을 넘긴다. 연결 상태는 `ConnectionDots` 의 상태 계산(`gatewayDot`·`bridgeDot`)을 그대로 두고 그리는 부분만 단추 하나로.

**Tech Stack:** React 19 · Tailwind v4 · `radix-ui` 1.6.7 · lucide-react · Vitest + Testing Library

**Spec:** `docs/superpowers/specs/2026-11-19-ui-polish-design.md`

## Global Constraints

- 사람 아바타는 테두리 없음, 에이전트는 2px 에이전트 색 테두리(스펙 7.2) — U4 는 채움만 더한다.
- 작성기·메시지·머리·사이드바에서 12px 미만 글자 금지(U2~U5).
- 데스크톱(`useIsNarrow` 거짓) 머리의 단추 배치·접근 이름은 바꾸지 않는다(U6).
- 390px 가로 스크롤 금지.
- 줄기 A 는 `ui/button.tsx`·`ConnectionDots.tsx`·`Sidebar.tsx`·`features/auth/*` 를 건드리지 않는다. 줄기 B 는 `ui/avatar.tsx`·`ui/identity-avatar.tsx`·머리 셋·`DirectRow.tsx`·`MessageItem.tsx` 를 건드리지 않는다.
- 서브에이전트·포크 금지, `git stash` 금지, 경로 명시 stage, Conventional Commits(`feat(web): …`), `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- 시험은 실행 수와 함께 보고. `pnpm test` 는 typecheck·build 와 동시에 돌리지 않는다.

## Review Focus

- 좁은 화면에서 「더 보기」로 옮긴 동작이 데스크톱과 **같은 일**을 하는가 — 특히 대화상자를 여는 「에이전트 초대」, 권한이 없을 때 빠지는 「새 세션」, 닫힌 세션의 「세션 닫기」 대신 동작 → Task A4 `overflow mirrors desktop actions`.
- 좁은 화면 ↔ 넓은 화면 전환(창 폭 바뀜) 때 열린 메뉴·대화상자가 깨지지 않는가 → Task A4 `resize while menu open`.
- 사진이 있는 아바타는 이니셜·채움을 그리지 않는가(사진이 늦게 오면 그 사이만 이니셜) → Task A1 `image wins over initials`.
- 이름이 이모지·공백으로 시작하거나 빈 글인 사람의 이니셜 → Task A1 `initial of odd names`(첫 글자소, 빈 글이면 「?」).
- 연결 상태에서 Gateway 이름이 아주 길 때 사이드바 폭(260px)을 넘지 않는가 → Task B1 `long gateway name truncates`.
