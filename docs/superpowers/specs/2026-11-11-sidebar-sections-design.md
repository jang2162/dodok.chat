# 사이드바 개인 섹션 — 설계

상태: 승인(2026-11-11, 사용자와의 대화)

## 1. 왜

채널과 DM 을 사람마다 자기 분류로 묶어 사이드바에 보고 싶다(사용자 — 「분류별로 채널과 DM 을 그룹핑」). 슬랙의 섹션처럼 한 섹션에 채널과 DM 이 섞인다.

## 2. 목표 · 하지 않을 것

**목표** — 개인 섹션 만들기·이름 바꾸기·지우기·순서 바꾸기·접기, 채널·DM 을 섹션에 넣고 빼기와 섹션 안 순서를 메뉴와 끌어다 놓기 둘 다로.

**하지 않을 것** — 팀이 함께 쓰는 섹션, 한 항목을 여러 섹션에, 기본 두 절(「채널」·「다이렉트 메시지」)의 순서 바꾸기, 섹션별 알림 설정.

**실패로 볼 것** — 섹션 때문에 채널·DM 이 사이드바에서 사라지는 것(읽을 수 있는 것은 늘 어딘가에 보여야 한다), 다른 사람이 내 섹션을 보는 것, 읽지 않음 표시가 섹션 안에서 빠지는 것.

## 4. 접근

끌어다 놓기는 `@dnd-kit`(core·sortable)를 들인다 — 마우스·터치·키보드 센서와 접근성 안내(announcements)를 한 번에 준다. 브라우저 기본 HTML5 끌어다 놓기는 모바일 터치가 안 돼 B5 와 맞지 않고, 직접 만드는 것은 접근성까지 맞추기에 크다. 웹에는 지금 끌어다 놓기 의존성이 없다.

저장은 사람마다 배치 한 벌(문서 하나)로 둔다 — 섹션 목록이 작고(≤50) 한 사람만 쓰므로, 표를 둘로 나눠 행 단위로 고치는 것보다 통째로 읽고 쓰는 쪽이 끌어다 놓기 결과(여러 항목의 순서가 한 번에 바뀜)를 그대로 담는다. 같은 사람의 두 탭이 동시에 고치면 나중 저장이 이긴다(개인 자료라 받아들인다) — 저장 뒤 wire 로 다른 탭이 새 배치를 받는다.

## 5. 설계

- **데이터** — 표 `user_sidebar_layouts`(`user_id` PK·FK, `layout_json`, `updated_at`). 배치: `{ sections: [{ id, name, collapsed, items: ChannelId[] }] }`(배열 순서가 화면 순서).
- **계약(shared)** — `SidebarLayout` Zod(섹션 ≤50, 이름 trim 뒤 1~40자, 섹션 id 는 클라이언트가 만든 UUID, 항목 id 중복 금지 — 섹션 사이도). REST `GET /api/v1/me/sidebar` → 배치(없으면 빈 배치), `PUT /api/v1/me/sidebar` 본문 배치 → 저장한 배치. wire user 룸 `me.sidebar`(`{ layout }`).
- **서버** — PUT 은 항목 id 가 그 사람이 지금 읽을 수 있는 채널(DM·그룹 DM 포함 — `readableChannelSql`)인지 보고, 아닌 id 는 **지우지 않고 그대로 둔다**(보관·잠시 접근 잃음 뒤 돌아올 수 있게 — B7). GET 은 저장된 그대로 돌려주고, 화면이 지금 목록에 없는 id 를 그리지 않는다. 존재하지 않는(삭제된) 채널 id 는 PUT 때 걷는다.
- **웹** — `Sidebar.tsx` 가 섹션들을 「채널」·「다이렉트 메시지」 절 위에 그린다. 각 항목은 지금의 채널·DM 링크 컴포넌트를 그대로 써 읽지 않음·접속 점이 같게 보인다. 섹션 머리: 이름·접기·안 읽은 표시(접혔을 때)·「⋯」(이름 바꾸기·위로·아래로·지우기). 항목 메뉴: 「섹션으로 옮기기 → 섹션들 / 새 섹션… / 섹션에서 빼기」. 「＋ 섹션 만들기」. 끌어다 놓기: 섹션 사이·섹션 안 순서·기본 절로(=빼기)·섹션 순서. 바꾸면 낙관적으로 그리고 PUT, 실패면 되돌리고 토스트. 모바일 시트 사이드바도 같다.
- **문구** — 라벨·단추만(2026-11-10 문구 기준).

## 6. 확인

- shared: 상한·중복·빈 이름. 서버: GET 빈 배치, PUT 저장·wire, 남이 못 읽는 id 포함 PUT, 없는 채널 id 걷기, 다른 사람 배치와 섞이지 않음. 웹: 섹션 그리기·접기·안 읽은 표시·메뉴 넣기/빼기/새 섹션·지우기 뒤 기본 절로·보관 채널 숨김·wire 반영·끌어다 놓기(키보드 센서로 시험)·실패 되돌림.
- dev:fake 화면 확인(마우스 끌기·키보드·좁은 화면 시트).
