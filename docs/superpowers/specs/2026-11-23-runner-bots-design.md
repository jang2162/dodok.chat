# 러너 봇 — 프로젝트 없는 봇 폴더와 봇 정의(1부) — 설계

상태: 승인 대기(2026-11-23) · 결정: 사용자와의 대화(2026-11-23), 빌더 확인 1회

## 1. 왜

Orca 의 bots 처럼(봇마다 자기 폴더 `~/.orca/bots/<이름>`, 목적이 `SOUL.md` 첫 줄, 「지켜볼 것·할 일·보고할 것」, 템플릿, 봇 전용 도구·로그인) dodok 에서도 **저장소·프로젝트 없이** 봇을 만들고 싶다(사용자). 지금 러너 에이전트는 반드시 프로젝트(러너 루트 안 디렉터리)를 골라야 한다.

사용자는 범위 C(폴더 + 정의 + 봇 전용 도구·로그인)를 골랐고, 세 부분으로 나눠 차례로 하기로 했다(사용자 승인): **1부 봇 폴더·봇 정의(이 문서)**, 2부 봇 전용 도구(MCP — 러너 로컬 천장으로 묶음), 3부 도구 로그인(OAuth). 2·3부는 따로 설계한다.

## 2. 목표 · 하지 않을 것

**목표**
- 러너 에이전트를 만들 때 프로젝트 대신 **「봇(폴더만)」**을 고른다 — 러너가 그 봇 전용 폴더를 만들고 런은 그 폴더에서 돈다.
- 봇 정의(목적 한 줄·지켜볼 것·할 일·보고할 것)를 만들 때 적고, 에이전트 상세에서 고친다. 러너가 그 폴더의 `SOUL.md` 로 쓰고 런마다 지시에 넣는다.
- 템플릿 넷(리뷰·릴리스·지원·빈 봇)에서 시작할 수 있다.

**하지 않을 것**
- 「지켜볼 것」을 실제 트리거로(GitHub 이슈가 오면 깨우기 등) — 정해진 때 깨우기는 기존 자동화(예약·웹훅)를 쓴다.
- 봇 전용 도구·로그인(2·3부).
- 봇 폴더를 git 으로 두기, 워크트리, 봇을 다른 러너로 옮기기.
- 보관 때 폴더 지우기(남긴다 — 지우는 건 러너 머신의 사람).

**실패로 볼 것**
- 봇 폴더가 러너 허용 루트 밖이라는 이유로 런이 천장에서 막히는 것(봇 폴더는 러너가 따로 허용해야 한다).
- 핸들·이름으로 봇 폴더 경로가 봇 폴더 자리 밖으로 새는 것(`..`·`/`·심볼릭 링크).
- 옛 러너에 봇 에이전트가 붙어 아무 답 없이 멈추는 것.
- `SOUL.md` 를 사람이 러너 머신에서 고쳤는데 다음 런이 말없이 덮어쓰는 것(1부 결정 B4 로 다룬다).

## 4. 방법

봇을 「프로젝트 종류 하나」(러너 프로젝트 행에 `kind: bot`)로 넣는 길도 있었다 — 프로젝트 화면·천장을 다시 쓰지만, 봇은 루트 밖 러너 관리 자리이고 에이전트 하나에 하나라 프로젝트의 루트·이동·보관 규칙과 맞지 않는다. 에이전트에 붙은 정의로 둔다(B2).

## 5. 남은 것(빌더 몫)

- 러너 천장의 봇 자리 판정(`botsDir` realpath 아래 정확히 `<id>` 한 단계, 없으면 만든다, 심볼릭 링크 거절).
- 봇 정의를 지시 틀에 렌더하는 문장 꼴(B9).
- `runnerProjectId` 를 전제하는 자리 정리 — 빌더 확인이 센 서버·웹·shared 41곳 중 프로젝트가 있어야만 도는 셋(`runners/definition.ts` 런 정의의 innerJoin, `agents/commands.ts` 명령 목록, `restoreAgent`)은 봇 갈래가 필요하다.
- 웹: 「봇」 선택·템플릿·네 칸, 에이전트 상세의 정의 편집, 연결 트리에서 봇 에이전트 자리(러너 아래 「봇」 묶음).
- 시험·런 0회 하네스·문서(`docs/manual/user-guide.md`·`docs/guides/agent-guide.md`·`docs/guides/plan.md`). 러너 0.9.0 은 조율자.

## 6. 2부로 넘긴 결정(2026-11-23)

- **러너 제어 내장 도구** — 봇을 만들 때 고를 수 있는 내장 도구로 「이 러너 설정 제어」를 둔다(사용자). 범위는 **앱에 있는 그 러너의 설정**(프로젝트·워크트리 추가·보관, 러너 에이전트·봇 만들기, 세션 시작값, 원격 업데이트 실행)이고, 러너 머신의 로컬 설정(천장 — 루트·프로그램·권한 상한·`remoteUpdate`)은 건드리지 않는다(사용자 A). 지금 제어 도구(채널 안 에이전트의 제어 도구 — 쓰기는 시킨 사람의 확인 카드)를 그 러너 범위로 좁혀 붙이는 꼴로 2부에서 설계한다.
