# 메시지 링크 복사와 맥락 넘기기 — 설계

날짜: 2026-11-25 · 상태: 검토 대기

## 왜

사용자 요청(2026-11-25): 「메시지 링크 복사하는 기능 추가해줘. 맥락 제공할때 사용목적」. 다른 채널·세션·스레드의 메시지를 가리켜 에이전트에게 「이거 보고 해 줘」라고 넘기고 싶다. 사람끼리 「이 글 봐」로 공유하는 데도 쓴다. 시안: UI 개선 시안 07 절(아티팩트 `https://claude.ai/artifact/V58LQN2ti5dD46iN2mHDtr`).

지금은 메시지를 가리키는 주소가 없다. 검색의 「결과로 가기」(`jumpToSeq`)는 그 자리로 가는 동작만 있다. 에이전트는 링크를 받아도 제어 도구 `read_messages` 로 스스로 찾아 읽어야 한다.

## 목표

- 메시지마다 **「링크 복사」** — 그 메시지를 여는 주소를 클립보드에.
- 주소를 열면 그 메시지 자리로 가서 강조한다(채널 세션 타임라인 또는 스레드). 볼 수 없는 메시지면 「볼 수 없는 메시지입니다」.
- 그 주소를 글에 붙여 보내면, **그 글로 시작한 에이전트 런은 링크한 메시지의 내용을 문맥으로 받는다** — 에이전트가 도구를 부르지 않아도 된다. 이것이 요청의 핵심 목적이다.
- 사람에게는 보낸 글 안의 링크가 작은 인용 카드(작성자·자리·첫 줄)로 보인다. 작성 중에도 같은 카드가 미리 보인다.

## 비목표

- 외부 사이트 링크 미리보기(일반 unfurl).
- 링크 권한을 넓히는 것 — 링크는 열람 권한을 주지 않는다. 읽을 수 있는 사람에게만 내용이 보인다.
- 메시지 범위 선택(여러 개)이나 「여기부터 여기까지」 링크.

## 접근

1. **(고른 것) A. 서버가 런을 시작할 때 링크를 펼친다.** 글 본문은 링크 그대로 저장하고, `buildInboundDeliver` 가 본문에서 같은 앱의 메시지 링크를 찾아 시킨 사람이 읽을 수 있는 것만 `InboundContext.linkedMessages` 로 싣는다. 헤더 줄은 shared 함수 하나로 플러그인·러너가 같이 만든다. 이미 `threadUpdates`·`reactions` 가 같은 길(선택 필드, 옛 플러그인은 버림)이다. 권한은 런마다 서버가 본다.
2. B. 웹이 보낼 때 인용문을 본문에 넣는다. 서버 변경이 없지만 채널 글이 길어지고, 원문이 고쳐져도 낡은 사본이 남고, 다른 사람이 못 읽는 DM 내용을 채널에 그대로 퍼뜨리기 쉽다.
3. C. 에이전트가 링크를 보고 `read_messages` 를 부른다. 에이전트마다 결과가 들쭉날쭉하고 턴이 늘어난다. 지금도 가능한 길이라 목표가 아니다.

방법 고르기는 사용자가 맡겼다 — A 는 이 문서 작성자의 판단이다.

## 정한 것

### 주소

- 꼴: `<APP_ORIGIN>/c/<channelId>/s/<conversationId>?m=<messageId>`. 스레드 답글이면 `<APP_ORIGIN>/c/<channelId>/s/<conversationId>/t/<rootId>?m=<messageId>`. DM·그룹 DM 도 지금 그 화면의 주소 꼴에 `?m=` 을 붙인다(빌더가 라우트에 맞춘다).
- 주소는 웹이 만든다(`window.location.origin` 기준). 서버의 링크 찾기는 `APP_ORIGIN` 과 같은 오리진만 본다 — 다르면 보통 링크.
- 웹이 `?m=` 이 붙은 주소를 열면: 새 REST `GET /api/v1/messages/:id`(읽기 권한은 `getReadableConversation` 과 같은 판정, 못 읽거나 없으면 404) 로 seq 를 얻어 `jumpToSeq`, `HIGHLIGHT_MS` 강조. 404 면 토스트 「볼 수 없는 메시지입니다」 후 그 대화(또는 채널)만 연다. 주소의 채널·대화와 응답이 다르면 응답을 따른다(메시지가 옮겨 갈 일은 없지만 손으로 고친 주소 대비).

### 복사 자리

- 메시지 호버 도구 줄에 🔗(접근 이름 「링크 복사」), 메시지 「⋯」 메뉴의 「링크 복사」, 좁은 화면 길게 누르기 메뉴.
- 클릭 핸들러 안에서 `navigator.clipboard.writeText`. 성공하면 토스트 「링크를 복사했습니다」, 실패하면 주소를 선택된 읽기 전용 칸으로 띄운다.

### 사람에게 보이는 카드

- 작성기: 붙여넣거나 입력한 본문에 위 꼴의 같은 오리진 링크가 있으면 작성기 위(첨부 자리)에 인용 카드 — 미리보기일 뿐이다. ✕ 는 **작성 중 미리보기만** 닫는다(웹 상태, 저장하지 않는다). 보낸 글에는 늘 카드가 서고, 에이전트 문맥에서 빼려면 링크 글을 지운다(내 판단 — 숨김을 저장하려면 메시지 스키마가 늘어난다).
- 보낸 글: 본문의 같은 오리진 메시지 링크마다(최대 3개) 본문 아래 인용 카드 — 보는 사람 권한으로 `GET /messages/:id`. 못 읽으면 카드 없이 링크 글만. 카드를 누르면 그 메시지로 간다.
- 카드 내용: 작성자 아바타·이름, 「# 채널 · 세션 제목(· 스레드) · 시각」, 본문 첫 2줄(멘션은 @핸들, 마크다운 걷음 — `ReplyBundle` 의 `previewOf` 와 같은 규칙).

### 에이전트 문맥

- shared `InboundContext.linkedMessages?: LinkedMessage[]`(최대 3, 선택 필드). `LinkedMessage`: `messageId`, `channelName`, `conversationTitle`, `threadRootId?`, `author: { type: "user"|"agent"|"system"|"automation"; handle }`, `text`(`renderForAgent` 결과, 4,000자에서 자름), `ts`, `attachments`(이름만, 최대 10), `root?`(스레드 답글이면 루트 — `author`·`text` 1,000자).
- 서버 `buildInboundDeliver`: 트리거 메시지 본문에서 링크를 찾는다(순서대로 최대 3, 같은 id 는 한 번).
- **펼치는 런**: 종류 `mention`·`auto_respond`·`relay`(트리거 글의 작성자가 사람·에이전트·자동화 누구든). `interaction`·`continue`·`command`·`background` 에는 싣지 않는다(`packages/shared/src/domain/index.ts` 의 런 종류).
- **읽기 판정은 제어 도구와 같은 `readerOf(principal)`**(`apps/server/src/auth/channel-access.ts`) — 그 런의 주체(시킨 사람, 릴레이면 체인을 시작한 사람, 사람 없는 자동화면 일반 채널만)로 보되, **DM·그룹 DM 은 그 런이 도는 바로 그 DM 일 때만 연다.** 그래서 사람이 자기 DM 의 링크를 일반 채널에 붙여도 채널의 에이전트에게는 펼치지 않는다 — DM 내용이 채널 답으로 새는 것을 막는 지금 규칙(에이전트 DM 계획 PD3)을 그대로 지킨다(내 판단, 안전한 쪽. 사람 화면의 카드는 보는 사람 권한이라 본인에게는 보인다). 못 읽으면 조용히 뺀다(링크 글은 본문에 남는다).
- 넣는 자리: 플러그인은 헤더 `formatInboundContext`(이미 「최근 대화」로 남의 글을 싣는 자리). **러너는 `buildTurnFacts` 가 아니라 사용자 메시지 본문을 만드는 `renderRunnerPrompt`**(`packages/shared/src/runner/prompt.ts`, 최근 대화가 드는 쪽) — `buildTurnFacts` 는 「dodok 러너가 붙인 문맥이며 대화 상대가 쓴 글이 아닙니다」로 시작해 남의 글을 넣으면 그 말이 거짓이 되고 주입 통로가 된다(빌더 점검). 두 자리가 shared `formatLinkedMessages(list, hhmm)` 하나를 쓴다. 꼴(예):
  ```
  링크한 메시지 1:
  [14:11] @erdd (#dodok-dev · 세션 「스레드 UI 개선」 · 스레드): 스키마 변경안 정리했습니다 — …
  ```
  본문 안 줄바꿈은 유지하되 각 줄 앞에 두 칸 들여쓰기(헤더 줄로 오인되지 않게 — `foldHeaderText` 의 까닭과 같은 문제). 정확한 꼴은 빌더가 정하고 시험으로 못 박는다.
- 플러그인은 원격 업데이트(U5)로 나간다. 옛 플러그인은 필드를 버리고 링크 글만 본다.

## 빌더에게 남긴 것

- 링크 찾기 정규식(쿼리 순서·끝 문장부호·마크다운 링크 `[..](url)` 안의 주소).
- 카드 조회의 묶음 요청(한 화면에 링크가 많을 때 — 캐시 키 `["message", id]`).
- DM·그룹 DM 라우트의 정확한 꼴.

## 시험

- shared: `LinkedMessage` 파싱, `formatLinkedMessages` 꼴·자르기·들여쓰기.
- 서버: 링크 찾기(같은 오리진만·최대 3·중복), 권한(남의 DM 링크·**내 DM 링크를 일반 채널에 붙인 것**은 빠짐, 같은 DM 안 링크는 실림), 릴레이·자동화 주체, `command`·`interaction`·`continue`·`background` 제외, `GET /messages/:id` 404.
- 플러그인: 헤더에 줄이 실림. 러너: 사용자 메시지 본문에 실리고 `buildTurnFacts` 에는 없음. 둘 다 필드 없으면 줄 없음.
- 웹: 복사(클립보드 성공·실패), `?m=` 진입 강조·404 토스트, 작성기 카드·✕, 보낸 글 카드·못 읽으면 없음.
- 런 0회 하네스(live-smoke 「Claude 러너 런 0회 하네스」)로 러너 프롬프트에 줄이 실리는지 본다 — 모델 런은 하지 않는다.

## 구현과 맞춘 것

구현(2026-11-25)이 이 문서와 달라진 것만 적는다.

- **오리진 전달** — 서버의 링크 찾기가 쓰는 `APP_ORIGIN` 은 `createServices`(`apps/server/src/wiring.ts` `ServicesDeps.appOrigin`) → 오케스트레이터(`OrchestratorDeps.appOrigin`) → `buildInboundDeliver` 의 `origin` 으로 넘긴다. 없으면(시험·옛 배선) 펼치지 않는다.
- **DM 자리 이름** — `LinkedMessage.channelName` 은 DM·그룹 DM 이면 채널 행 이름(`dm`·`direct`) 대신 `DM`·`그룹 DM` 이다. `GET /api/v1/messages/:id` 는 세 칸에 더해 `channelKind` 를 싣는다(카드가 「#」 를 붙일지 가른다). 꼴이 틀린 id 는 400 이고 웹은 404 와 같이 「볼 수 없음」으로 본다.
- **시스템 메시지** — 링크한 메시지가 시스템 글이면 에이전트 문맥에서 뺀다. 시스템 메시지에는 「링크 복사」가 없다.
- **복사 자리** — 메시지에는 「⋯」 메뉴·길게 누르기 메뉴가 없어 동작 줄의 🔗 버튼 하나다(스레드에서 답하기·반응 추가 왼쪽). 터치 화면에서는 다른 동작 버튼처럼 늘 보이고, 머리 줄 없는 메시지의 본문 오른쪽 여백을 버튼 수만큼 넓힌다. 복사가 실패하면 「링크를 복사하지 못했습니다」 토스트 안에 주소가 선택된 읽기 전용 칸을 15초 띄운다.
- **카드** — 카드를 누르면 `?m=` 주소로 간다(진입 길이 강조한다). 미리보기는 `ReplyBundle` 의 `previewOf` 를 줄 수 인자로 넓혀 쓰고, 빈 줄과 함께 가로줄(`---`·`***`·`___`)도 건너뛴다. 작성기 ✕ 뒤에는 초점을 입력으로 돌려준다(누른 ✕ 가 사라져 Enter 가 body 로 가던 것 — 브라우저 확인에서 찾았다).
- **진입** — `?m=` 은 세션 라우트의 검색 값(`validateSearch`)이고 스레드 라우트가 물려받는다. 스레드 주소로 들어오면 `view=main` 은 남기고 `m` 만 지운다.
- **웹 모듈** — 복사·조회·진입·🔗 버튼은 JSX 를 담아 `apps/web/src/features/messages/messageLink.tsx` 다.
- **플러그인·러너 판본** — 올리지 않았다. 원격 업데이트의 플러그인 「최신」은 서버가 품은 빌드이고 `linkedMessages` 는 선택 필드라 옛 플러그인·옛 러너는 버리고 받는다(블록이 없을 뿐). 러너는 사용자 메시지 본문(`renderRunnerPrompt`)을 러너 머신에서 그리므로 블록은 이 기능이 든 러너 판부터 실린다 — 러너 판본·배포는 `docs/guides/runner-release.md` 대로 따로 정한다.
